# Third-party references and attribution

This update studied design patterns from the following projects. Upstream skill files, scripts, agent prompts, and plugins were not copied in full; the implementation in this repository was written for the existing Agent Skills architecture.

## Agustino Halim — academic-writing-skills
https://github.com/agustinohalim/academic-writing-skills

Design references: thesis as one connected research chain, deterministic bookkeeping separated from academic judgment, explicit not-assessable status, quote validation, and revision-impact review. Upstream declares MIT for `plugins/**/scripts/` and CC BY 4.0 for other content. This update does not copy upstream expressive text or scripts. Attribution: Agustino Halim, academic-writing-skills.

## Haiwen Huang — academic-writing-agents
https://github.com/andrehuang/academic-writing-agents

Design references: specialist review lenses (logic, consistency, technical/methodology, adversarial review), review-before-edit, and prioritized synthesis. Upstream MIT. Attribution: Haiwen Huang, academic-writing-agents.

## Awesome Academic Writing Skills contributors — awesome-academic-writing-skills
https://github.com/BettyXu2001/awesome-academic-writing-skills

Design references: reusable research record, claim-evidence traceability, separation of integrity audit from drafting, and revision handoffs. Upstream MIT. Attribution: Awesome Academic Writing Skills contributors.
